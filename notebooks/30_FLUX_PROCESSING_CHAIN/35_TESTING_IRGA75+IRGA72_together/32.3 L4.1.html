🟢Level-4.1: GAP-FILLING

  • Introduced in diive v0.85.0, gap-filling can now be done using both random forest and MDS
  • For gap-filling using MDS, make sure that variables are in the required units: short-wave incoming radiation in W m-2, air temperature in °C, VPD in hPa

Parameters: - mds_settings are parameters for the MDS gap-filling method, see docstring here for more details - rf_settings are parameters for scikit’s RandomForestRegressor model, see their official documentation for allowed parameters - ml_feature_settings are general settings for machine-learning models (such as random forest)
