Flux post-processing chain: IRGA72 input, Level-1 fluxes and meteo (2016-2026.09)

Modified

27 October 2026

notebook version: 4 (27 Oct 2026)

ℹ️ About this notebook

Joins the merged Level-1 fluxes of the IRGA72 gas analyser (20_L1_FLUXES/IRGA72/99) with the merged meteo products (10_METEO/30_PRODUCTS/99) on one 30MIN index, and stores the result in the external data folder as parquet. The flux notebooks of this folder (01, 11, 15) read this file: the gap-filling of Level 4.1 takes its drivers from the meteo columns.

No value is computed or corrected here. The flux columns are exactly what 20_L1_FLUXES/IRGA72/99 wrote and the meteo columns exactly what 99 wrote. The joined record runs from PERIOD_START, 1 January 2016 00:15, to 30 September 2026. The flux columns are empty before the first IRGA72 half-hour on 11 January 2016; the meteo columns hold values from the first record on.

This file has to be rebuilt whenever one of its meteo columns changes in 99. It takes only the tower meteo of the products 01 to 07 (METEOCOLS), which the chain uses. The soil, precipitation and outgoing radiation series that 99 also merges are not needed here; they reach the finalize set directly from 99.

📇 Data sources

  • 20_L1_FLUXES/IRGA72/99_IRGA72_L1_MERGED_2016-2026.09.parquet: the Level-1 fluxes, one record per half-hour, each record taken whole from one EddyPro run.
  • 10_METEO/30_PRODUCTS/99_METEO_MERGED_2004-2026.09.parquet: every merged meteo series with its provenance flags. Its own information file, 99_METEO_MERGED_2004-2026.09_INFO.md, describes the columns and flag codes.

Both live in the external data folder and are addressed by absolute path. Both are indexed on TIMESTAMP_MIDDLE, local standard time (UTC+01:00), so they are joined without any shift.

The meteo columns are those of METEOCOLS. The tower series of 01 to 07 arrive, the measured and the homogenised columns side by side, so the choice of driver stays with the chain. The meteo names end in _T1_47_1 and the EddyPro names never do, which the checks below assert. The EddyPro biomet columns were already dropped in 20_L1_FLUXES/IRGA72/99.

Two driver names changed against the 2016-2024 version of this file. It was built on an older meteo file. TA_T1_47_1_gfXG and SW_IN_T1_47_1_gfXG keep their names. Vapour pressure deficit is now VPD_T1_47_1, gap-filled and complete, beside VPD_T1_47_1_HOMOGENIZED, and the column VPD_T1_47_1_gfXG no longer exists. The raw, unfilled TA_T1_47_1, SW_IN_T1_47_1 and PPFD_IN_T1_47_1 are no longer carried.

# Both inputs live in the external (untracked) data folder and are addressed by absolute path, so

DATADIR = (r"<DATA_FOLDER>"

# TIMESTAMP_MIDDLE of the first and the last record. The record starts with the calendar year, before

🔗 Join

# The two column sets must not share a name, or one would silently replace the other.
assert all(METEO_SUFFIX in _c for _c in meteo.columns), "a meteo column lacks the meteo suffix"
assert not any(METEO_SUFFIX in _c for _c in flux.columns), "a flux column carries the meteo suffix"
assert not set(flux.columns) & set(meteo.columns), "the two inputs share a column name"

# The joined period runs from PERIOD_START to PERIOD_END on the meteo index, which starts in 2004.
# The flux record must lie inside it; before its first record the flux columns are empty.
_start, _end = pd.Timestamp(PERIOD_START), pd.Timestamp(PERIOD_END)
assert meteo.index[0] <= _start, "the meteo record starts after PERIOD_START"
assert flux.index[0] >= _start, "the flux record starts before PERIOD_START"
df = meteo.loc[_start:_end].join(flux, how='left')
df = df.reindex(sorted(df.columns), axis=1)

print(f"Joined: {len(df):,} records x {df.shape[1]} columns "
      f"({flux.shape[1]} flux, {meteo.shape[1]} meteo), {df.index[0]} -> {df.index[-1]}")

🔍 Checks

_period = meteo.loc[pd.Timestamp(PERIOD_START):pd.Timestamp(PERIOD_END)].index
assert df.index.equals(_period), "the joined index is not PERIOD_START to PERIOD_END"
assert df.index[0] == pd.Timestamp(PERIOD_START) and df.index[-1] == pd.Timestamp(PERIOD_END)
assert len(df.columns) == flux.shape[1] + meteo.shape[1], "a column was lost or duplicated"

# Nothing was changed on the way: every column equals its source.
# Before the first flux record every flux column is empty.
_before = df.index < flux.index[0]
assert df.loc[_before, flux.columns].isna().all().all(), "flux values before the flux record"
for _c in flux.columns:
    assert df.loc[flux.index, _c].equals(flux[_c]), f"flux column {_c} changed in the join"
for _c in meteo.columns:
    assert df[_c].equals(meteo.loc[_period, _c]), f"meteo column {_c} changed in the join"
print(f"{int(_before.sum()):,} records before the first flux record ({flux.index[0]}) carry meteo only")

# The gap-filling drivers must hold a value at every timestamp.
for _c in DRIVERS:
    _n = int(df[_c].isna().sum())
    assert _n == 0, f"driver {_c} has {_n} missing values over the joined period"
print(f"Index, columns and values verified. Drivers complete: {', '.join(DRIVERS)}")
