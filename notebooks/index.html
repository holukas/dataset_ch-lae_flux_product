Modified

4 September 2026

104 working research notebooks, grouped by the folder they live in. The number is the notebook’s own prefix and orders the notebooks within a folder, so 01 in 10_METEO/30_PRODUCTS is the incoming shortwave product. A folder whose notebooks have no dependency order does not number them, so the column is empty there. Outputs are shown exactly as committed in the notebook; the notebooks are not re-executed at build time.
