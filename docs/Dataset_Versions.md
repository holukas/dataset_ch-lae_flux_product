# Dataset Versions

Each release of the dataset has its own page. The
[differences between versions](Version_Differences.md) are compared in one table.

| Version | Period | Fluxes from | Status |
|---|---|---|---|
| [FP2026.1](Version_FP2026.1.md) | January 2016 to September 2026 | enclosed-path LI-7200 (`IRGA72`) | current version, released 27 October 2026 |
| [FP2026.2](Version_FP2026.2.md) | 2004 to September 2026 | open-path LI-7500 (`IRGA75`) for 2004-2015, LI-7200 from 2016 | in progress; will supersede FP2026.1 |

: Releases of the CH-LAE flux product documented on this site. {#tbl-versions}

Both versions are available on request from the
[Grassland Sciences group, ETH Zurich](https://gl.ethz.ch/).

## Earlier CH-LAE datasets

FP2026.1 is the first release documented on this site. Earlier CH-LAE datasets were produced with
other processing and published separately:

- [CH-LAE FP2022 (2004-2022)](https://doi.org/10.3929/ethz-b-000582198), ETH Zurich Research
  Collection
- [CH-LAE FP2021 (2004-2020)](https://www.swissfluxnet.ethz.ch/index.php/documentation/ch-lae-fp2021-2004-2020/)

The flux versions calculated for each year before this dataset are listed in the
[Yearly Notes](Yearly_Notes.md).
