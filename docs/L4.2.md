# Level-4.2: NEE partitioning

The partitioning of `NEE` into gross primary production (`GPP`) and ecosystem respiration
(`RECO`) is **not part of FP2026.1**. It is switched off in
[`05_FPPC_IRGA72_NEE`](notebooks/30_FLUX_POST-PROCESSING_CHAIN/IRGA72/05_FPPC_IRGA72_NEE_2016-2026.09.html)
(`RUN_PARTITIONING = False`).

When switched on, the notebook partitions the `NEE` of each USTAR scenario, gap-filled with
XGBoost, with the nighttime method (Reichstein et al. 2005) and the daytime method (Lasslop et al.
2010) as implemented in ONEFlux. ONEFlux itself partitions a flux gap-filled with MDS, so the
results would differ from ONEFlux output. See
[diive: partitioning](https://diive.readthedocs.io/en/latest/flux_postprocessing.html#partitioning).
